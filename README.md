# 8086 Assembly Programs

A collection of 8086 microprocessor assembly language programs written for DOS-based assemblers. The examples cover arithmetic, strings, arrays, sorting, searching, date and time services, and basic DOS interrupt operations.

## Contents

### Arithmetic and Number Programs

- `add.asm` - Add two numbers
- `add1.asm` - Addition example using input values
- `add2.asm` - Addition example
- `sub.asm` - Subtract two numbers
- `sub1.asm` - Subtraction example
- `div.asm` - Division example
- `2sum.asm` - Two-sum style calculation
- `sum2.asm` - Sum calculation
- `gcd.asm` - Calculate the greatest common divisor
- `fibo.asm` - Generate Fibonacci numbers
- `largest.asm` - Find the largest value

### String Programs

- `str.asm` - Basic string operations
- `str1.asm` - String processing example
- `concat.asm` - Concatenate strings
- `length.asm` - Find the length of a string
- `replace.asm` - Replace characters in a string

### Array and Sorting Programs

- `sort.asm` - Sort values in an array
- `2sum.asm` - Find a pair-based sum
- `largest.asm` - Find the largest value in a collection

### Input, Output, and System Programs

- `hello.asm` - Display a hello message
- `input.asm` - Read input from the keyboard
- `inputp.asm` - Read and process input
- `clear.asm` - Clear the screen
- `memory.asm` - Memory-related demonstration
- `date.asm` - Work with the system date
- `systime.asm` - Work with the system time

## Requirements

- DOSBox or another DOS-compatible environment
- MASM or TASM assembler
- A DOS linker, if required by the assembler workflow
- Basic knowledge of 8086 registers, instructions, and DOS interrupts

The repository includes DOS development tools and compiled files for reference. DOSBox is recommended for assembling and running these programs on modern systems.

## Running Programs with DOSBox

1. Install DOSBox.
2. Clone or download this repository.
3. Mount the repository folder inside DOSBox. For example:

	```text
	mount c /Users/your-name/Desktop/8086
	c:
	```

4. Assemble a program with MASM. A typical workflow is:

	```text
	masm add.asm;
	link add.obj;
	```

5. Run the generated executable:

	```text
	add.exe
	```

The exact commands can vary depending on the assembler version. Pre-built `.EXE` and `.OBJ` files are included for many examples.

## Typical TASM Workflow

```text
tasm add.asm
tlink add.obj
add.exe
```

Replace `add.asm` with the source file you want to build.

## DOS Interrupts

Many programs use DOS interrupt `21h` for services such as:

- Reading keyboard input
- Displaying text
- Exiting a program
- Reading the system date
- Reading the system time

The source code is intended for a 16-bit DOS environment and may require small changes to run with a different assembler or emulator.

## Learning Goals

This collection is useful for practicing:

- 8086 registers and flags
- Data movement and arithmetic instructions
- Conditional and unconditional jumps
- Loops and counters
- Procedures and stack operations
- String instructions
- Array traversal
- DOS interrupt services
- Assembly, linking, and execution in DOSBox

## Notes

- File names may appear in uppercase after assembly because DOS tools commonly use uppercase output names.
- Some examples expect keyboard input and should be run from a DOSBox terminal.
- The generated `.OBJ` and `.EXE` files are included for demonstration and comparison.
- Programs may need updates for modern assemblers because this project targets the 8086 and DOS environment.
